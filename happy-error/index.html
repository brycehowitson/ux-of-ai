Enable Chrome Built-in AI

This demo uses Chrome's native Prompt API (Gemini Nano) running 100% locally on your machine.

1. Enable Prompt API in chrome://flags:
chrome://flags/#prompt-api-for-gemini-nano
Set to: Enabled
2. Look for Optimization Guide (if present):
chrome://flags/#optimization-guide-on-device-model
Search for "optimization guide" in flags and set to Enabled BypassPerfRequirement. (If missing in your Canary build, Chrome enables this automatically when Prompt API is on.)
3. Relaunch Chrome & Verify Component:
chrome://components
Look for Optimization Guide On Device Model and click "Check for update".
4. Quick Console Test: Open DevTools (F12) and run: await (window.ai?.languageModel || ai.languageModel)?.availability()
